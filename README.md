# DigitLens Pro
Professional Synthetic Index Intelligence Platform for Deriv Markets.

DigitLens Pro is a real-time market analysis and intelligence tool designed for Deriv synthetic indices. It monitors live tick behaviour, detects statistical deviations, scans multiple market categories across Volatility, Boom, Crash, Jump, Step, Bear, and Bull indices, and highlights high-confidence trading opportunities.

---

## Overview

DigitLens Pro continuously streams live market data via Deriv’s public WebSocket infrastructure and performs real-time analytics across:
- **Digit Frequency & Clustering** (0–9 distribution, hot/cold tracking)
- **Even / Odd Imbalance**
- **Over / Under Pressure**
- **Match / Differ Probability**
- **Rise / Fall Direction**
- **Cross-Market Opportunity Scanner**
- **Confidence Scoring Engine**

---

## Features

### Live Tick Streaming
Connects directly to Deriv's public WebSocket API, processing live ticks instantly with zero configuration.

### Comprehensive Market Coverage
Supports a wide range of Deriv synthetic markets:
- **Volatility Indices**: Volatility 10, 15, 25, 30, 50, 75, 90, 100, 150, 250 (including 1s and 2s variants)
- **Boom & Crash Indices**: Boom 300, 500, 1000 / Crash 300, 500, 1000
- **Jump Indices**: Jump 10, 25, 50, 75, 100
- **Step Indices**: Step 100, Step 500
- **Range Break / Bear & Bull Markets**: Bear Market Index, Bull Market Index

### Advanced Analytics Tools
- **Digit Frequency Distribution**: Tracks digits 0 through 9, highlighting dominant and suppressed patterns.
- **Even/Odd & Over/Under Analysis**: Monitors continuous probability shifts against fair value baselines.
- **Match/Differ & Rise/Fall Tracking**: Evaluates tick momentum and repeat probabilities.
- **Pro Scanner**: Automatically scans all active markets simultaneously, ranking opportunities by confidence score so you can instantly load the most profitable setups.

### Sleek Dark Theme UI
Designed with an immersive, low-latency, eye-friendly dark mode interface optimized for desktop and mobile web use.
